# Flint2 Web App

This package contains the progressive web application for Flint2, a privacy-first Obsidian-style Markdown workspace. The app is built with React, Vite, Tailwind CSS, TanStack Router, and React Query. It is ready for OPFS-first vault storage, local-first sync, and offline-first delivery.

## Getting started

```bash
pnpm install
pnpm --filter @flint2/web dev
```

Environment variables are configured via `.env.local` (see `.env.example`).
